# eatsHub Mockup: Requirements

> ร่าง v0.1 · 17 พ.ย. 2026 · อ้างอิงจาก [04_Mobile_Order.md](specs/04_Mobile_Order.md) และ [07b_BOH_Web_Admin.md](specs/07b_BOH_Web_Admin.md)

## 1. เป้าหมาย

- Mockup แบบคลิกได้ ให้ผู้บริหารได้เห็นแอป eatsHub อีกครั้ง
- Mobile-first, deploy บน **Vercel**
- **ไม่มี backend จริง** ข้อมูลทั้งหมดเป็น mock data จากสเปก เก็บสถานะ (ตะกร้า, ออเดอร์) ในหน่วยความจำ/`localStorage` ของเบราว์เซอร์
- Brand: สีหลัก `#FCBB18`, โลโก้จาก `brand/logo.svg` / `brand/logo-transparent.svg`

## 2. การตัดสินใจหลัก

| หัวข้อ | ข้อสรุป |
|---|---|
| Tech stack | React + Vite + Tailwind CSS (static site) + React Router |
| การแสดงผล | มือถือ: เต็มจอ · Desktop: แอปลูกค้าแสดงในกรอบโทรศัพท์กลางจอ |
| หลังบ้าน | Layout desktop ตามต้นฉบับ, บนมือถือ sidebar พับเป็นเมนู ☰ และตารางยุบเป็นการ์ด |
| ทางเข้า | หน้า Landing เลือก "แอปลูกค้า" / "ระบบหลังบ้าน" → หน้า Sign In ปลอม (กรอกไว้ให้แล้ว กดเข้าได้ทันที ไม่ตรวจรหัสผ่าน) |
| วิธีชำระเงิน | เก็บเงินปลายทาง (COD) · PromptPay QR (จำลอง) · PayPal (จำลอง) |

|---|---|---|---|
| C1 | Sign In | โลโก้, Email/Password (กรอกไว้แล้ว), ปุ่มเข้าสู่ระบบ, ปุ่ม Google (กดแล้วเข้าได้เหมือนกัน) | คลิกผ่าน |
| C2 | หน้าแรก | Header ที่อยู่ "บ้าน ⌄", ปุ่มค้นหา, Banner carousel 3 ภาพ, กริดหมวดอาหาร, รายการร้านใกล้เคียง 6 ร้าน | ใช้งานได้ |

| C4 | รายละเอียดร้าน | รูป, ชื่อ, ⭐, ♥, แถบ ยอดขั้นต่ำ/ระยะทาง/ค่าส่ง, แท็บ เมนู · ข้อมูล · ส่วนลด · รีวิว | แท็บเมนูใช้งานได้, แท็บอื่นแสดงผลอย่างเดียว |
| C5 | รายละเอียดเมนู | รูป, ตัวเลือก (radio), ตัวเลือกเพิ่มวัตถุดิบ (sheet, เลือก 1–4), ตัวนับจำนวน, ปุ่มเพิ่มในตะกร้า | ใช้งานได้ |
| C6 | แถบตะกร้าลอย | "N รายการ \| ยอด ฿ · ดูตะกร้า" เมื่อมีของในตะกร้า | ใช้งานได้ |

| C8 | Checkout | สรุปออเดอร์, ที่อยู่จัดส่ง (บ้าน/ออฟฟิศ), วิธีชำระเงิน, ปุ่มชำระเงิน | ใช้งานได้ |
| C9 | ชำระเงิน | PromptPay: แสดง QR + ปุ่ม "ชำระแล้ว" · PayPal: หน้ายืนยันจำลอง · COD: ข้ามไป C10 | จำลอง |

| C11 | แท็บออเดอร์ | การ์ดประวัติ (ออเดอร์ตัวอย่าง + ออเดอร์ที่เพิ่งสั่ง), badge สีสถานะ, ปุ่มติดตามคำสั่งซื้อ | ใช้งานได้ |
| C12 | แท็บบัญชี | โปรไฟล์ + รายการเมนูตามสเปก, ออกจากระบบ → กลับ Landing | แสดงผลอย่างเดียว |

### ข้อมูลตัวอย่าง

- **ร้าน:** ราชาอาหาร · แม่แดง ก๋วยเตี๋ยวลงเรือ · ลูกชิ้นทอด แม่ประนอม · หมูทอดเจ๊จง · อินเดีย ฟูด (เจริญนคร) · ปิ้งย่างในตำนาน
- **เมนู:** ตามสเปก (สุกี้รวมมิตร 102 ฿, ลูกชิ้นทอด 15 ฿, ทาโกะยากิ 45 ฿, บะหมี่หมูแดง 88 ฿ ฯลฯ) ร้านอื่นใช้เมนูที่เข้ากับประเภทร้าน
- **ไรเดอร์ที่รับออเดอร์:** นาย สมชาย ตั้งกันไจ ⭐4.5/5

## 4. Scope: ระบบหลังบ้าน

| # | หน้าจอ | สิ่งที่ต้องมี | ระดับ |
|---|---|---|---|
| A1 | Sign In | พื้นหลังเทาเข้ม, การ์ดขาว "กรุณาเข้าสู่ระบบ", ปุ่มเหลือง (กรอกไว้แล้ว) | คลิกผ่าน |
| A2 | Layout | Header ขาว + โลโก้ + ออกจากระบบ, sidebar สีเทาเข้ม (เมนูที่เลือกเป็นสีเหลือง), breadcrumb, footer สีเหลือง "Copyright © 2026 EatsHub" | ใช้งานได้ |
| A3 | รายชื่อไรเดอร์ | ค้นหา, กรองสถานะ, ปุ่ม "+ เพิ่มรายการ" (ไม่ทำงาน), ตาราง: ลำดับ · รหัส · ทะเบียนรถ/จังหวัด · ชื่อ/เบอร์ · ใช้งานล่าสุด · is logged · สถานะงาน · สถานะไรเดอร์ · ผู้แก้ไข/วันที่ · Action, pagination | ใช้งานได้ |
| A4 | เมนูอื่นใน sidebar | แสดงครบตามสเปกเพื่อให้เห็นภาพรวม แต่กดแล้วไม่ไปไหน (หรือ toast "ไม่อยู่ในขอบเขต Mockup") | แสดงผลอย่างเดียว |

- **Badge สถานะงาน:** Online เขียว · Offline แดง · Delivery ส้ม
- **Badge สถานะไรเดอร์:** Active เขียว · Block แดง
- **ข้อมูล:** ไรเดอร์ 10 คนตามสเปก + เพิ่มอีก 7 คนให้ครบ 17 รายการ (2 หน้า ตามตัวอย่าง "แสดง 1 ถึง 10 จาก 17 รายการ")

## 5. นอก Scope

ลงทะเบียน · ลืมรหัสผ่าน · หน้าย่อยในบัญชี · แชท · โทร · เขียนรีวิว · ตัวกรองขั้นสูง · เพิ่ม/แก้ไข/ลบไรเดอร์ · รายละเอียดไรเดอร์ · เมนูหลังบ้านอื่น · ระบบ login/ชำระเงินจริง
