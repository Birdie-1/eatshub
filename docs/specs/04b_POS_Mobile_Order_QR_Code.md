# 04b · POS Mobile Order Module (QR Code)

> สรุปจาก `04_FOC_MobileOrder_QR Code V1.0.pdf` (155 หน้า, v1.0, 7/11/2023, "เอกสารส่งมอบงานงวดที่ 6", จัดทำโดย Soft Debut Co., Ltd.)

## ภาพรวม

แม้ชื่อไฟล์จะเป็น "MobileOrder" แต่เอกสารนี้คือ **POS เวอร์ชันมือถือ/แท็บเล็ตสำหรับร้านค้า** ใช้สำหรับ
- พนักงานรับออเดอร์ที่โต๊ะ
- ลูกค้าสแกน **QR Code ประจำโต๊ะ** เพื่อสั่งอาหารเอง
- ห้องครัวและแคชเชียร์
- ตั้งค่าร้าน และดู Dashboard/รายงาน

ใช้ฐานข้อมูล POS ชุดเดียวกับ [01_POS_Module.md](01_POS_Module.md) (MSSQL `frsv345`, config `/frs/include/config.php`, `/frs/company/[Domain].ini`)

- **ดีไซน์:** header สีเหลืองมีลวดลายโค้ง, ปุ่มกลมไอคอนดำ, badge ชื่อร้านพร้อมจุดเขียว (ออนไลน์), ปุ่มล่าง "ย้อนกลับ | บันทึก" สีเหลือง
- **รองรับ:** มือถือ + iPad (จอห้องครัว/รายงาน)

## Workflow

ใช้ workflow "รับออเดอร์ออนไลน์ของร้านค้า POS" เดียวกับ POS Module (Customer → Cashier POS → Kitchen POS → Rider)

## หน้าจอหลัก

### 1. เข้าสู่ระบบ
- หน้าแรก: โลโก้ eatsHUB + ปุ่ม **เข้าสู่ระบบ** / **ลงทะเบียนผู้ใช้ใหม่**
- ลงทะเบียน: ชื่อร้าน, เบอร์ติดต่อ, e-mail · Login ด้วย e-mail + รหัสผ่าน
- ลืมรหัสผ่าน: กรอกอีเมล → ระบบส่งลิงก์ไปที่อีเมล → ตั้งรหัสใหม่

### 2. Home / เลือกร้าน
หลังล็อกอินจะเห็นรายชื่อร้านทั้งหมดที่ผู้ใช้เป็นเจ้าของหรือพนักงาน (เช่น "eatsHUB Hotel") พร้อมปุ่ม สร้างร้านค้าใหม่ · ค้นหาร้านค้า (สแกน QR เพื่อขอเข้าร่วมร้าน) · ตั้งค่าโปรไฟล์ (มี QR ประจำตัว)

เมนูในร้านแสดงตามสิทธิ์: **Cashier · Take Order · Chef · Shift · Dashboard · Reports · Shop Setting · Back to Home**

### 4. จัดการออเดอร์
1. **พนักงานรับออเดอร์ (Take Order):** เลือกโต๊ะ (แสดงจำนวนรายการและยอดของแต่ละโต๊ะ) → เลือกเมนูจากกริดรูป (มี badge ราคา) → รายละเอียดเมนู + ตัวเลือก + หมายเหตุ + จำนวน → "ใส่ตะกร้า" → ตรวจรายการ → **ส่งออเดอร์**
2. **ลูกค้าสั่งผ่าน QR Code:** เลือกโต๊ะ/ช่องทาง → แสดง **QR Code ประจำโต๊ะ** → ลูกค้าสแกนแล้วเลือกเมนูบนมือถือตัวเอง → ตรวจรายการ → **สั่งสินค้า**
3. **ห้องครัว (iPad/มือถือ):** แสดงออเดอร์แยกตามโต๊ะ กรองตามครัวได้ (ทั้งหมด, ครัวทอด, ครัวเครื่องดื่ม) → เมนูที่ทำเสร็จกด **"เสร็จสิ้น"** เพื่อนำออก เมื่อเสร็จครบทั้งออเดอร์ ออเดอร์จะหายไปจากจอ
4. **แคชเชียร์:** เลือกผู้ใช้และใส่รหัส → แสดงโต๊ะแบบ "ทุกโต๊ะ" (สีเหลือง = มีลูกค้า, สีขาว = ว่าง) หรือ "เฉพาะโต๊ะที่มีออเดอร์" → Invoice → พิมพ์ใบแจ้งหนี้ (Subtotal, Service Charge, VAT, Amount Net) → เลือกช่องทางชำระและส่วนลด → กรณีเงินสดใส่จำนวนเงินที่ได้รับ → ทอนเงิน

### 5. Dashboard / รายงาน
- เลือกช่วงเวลา **วันนี้ / สัปดาห์นี้ / เดือนนี้ / กำหนดเอง**
- ยอดขายรวม (เช่น ฿9,860.25), จำนวนบิล (14), ยอดเฉลี่ยต่อบิล (฿704.30), กราฟแท่งรายชั่วโมง
- ยอดแยกตามช่องทาง: **ทานที่ร้าน / Grab Food / Line Man / eatsHUB** (จำนวนบิล + ATV)
- Top Category / Top Product / Top Sale
- รายงานแยกประเภท: สินค้า · หมวดหมู่ · พนักงาน · ประเภทการชำระ · ใบเสร็จ · ช่องทางการขาย (กราฟวงกลม + ตาราง)
