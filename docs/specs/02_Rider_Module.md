# 02 · Rider Module (Mobile App for Rider)

> สรุปจาก `02_FOC_RiderModule V1.0.pdf` (96 หน้า, v1.0)

## ภาพรวม

แอปมือถือสำหรับคนขับ (Rider) ใช้รับงานส่งอาหาร นำทางไปร้านและไปหาลูกค้า ดูรายได้ และจัดการกระเป๋าเงิน
- **Tech:** Flutter (iOS/Android) เรียก Rider API ด้วย `api_key` + `cctr_no` · ฐานข้อมูล MySQL `eatshub`
- **ดีไซน์:** พื้นขาว ปุ่มหลักสีเหลือง eatsHub, bottom nav สีเทาเข้ม 4 แท็บ (หน้าแรก · กระเป๋าเงิน · รายได้ · บัญชี) และหน้าแรกเป็นแผนที่ Google Maps

## Workflow: รับงานและจัดส่งออเดอร์ (Customer → Rider → Store)

1. ลูกค้าสั่งออเดอร์ → ระบบจัดสรรคนขับ ส่งงานให้คนขับตามเงื่อนไข → คนขับได้รับแจ้ง สถานะ **รอกดรับงาน**
2. ถ้าเปิด **รับงานอัตโนมัติ** ระบบรับงานให้ ถ้าไม่เปิด คนขับต้องเลือก
   - **ปฏิเสธ (Reject):** ระบบหาคนขับคนถัดไป
   - **ไม่กดทันเวลา (Expired):** ถ้าเกินเวลาจัดสรรรวมแล้วไม่มีใครรับ ออเดอร์ถูกยกเลิก
3. **รับงาน** → สถานะ **Accepted** (กำลังไปร้าน) → ลูกค้าและร้านได้รับแจ้ง
4. **ถึงร้าน** → สถานะ **Arrived** → รอร้านเตรียมอาหาร (ถ้าร้านยังไม่รับออเดอร์ คนขับติดต่อร้านหรือยกเลิกพร้อมเหตุผลได้)
5. **รับอาหาร** → สถานะ **Delivering** → ลูกค้าได้รับแจ้ง "กำลังจัดส่ง" และ "ใกล้ถึง"
6. **ส่งอาหารแล้ว** (ลูกค้าเซ็นรับ) → สถานะ **Delivered** → หน้าสรุปรายได้ → ลูกค้ารีวิวร้านและคนขับ

## สถานะ (Enum จากฐานข้อมูล ใช้ทำ Mockup ได้ตรง)

| มุมมอง | ค่า |
|---|---|
| **คนขับต่อออเดอร์** (`his_driver_status`) | Waiting (รอกดรับ) → Accepted (กำลังไปร้าน) → Arrived (ถึงร้าน) → Delivering (ส่งอาหาร) → Delivered · Cancel · Reject · Expired |
| **ออเดอร์** (`his_order_status`) | Waiting → Accepted → Arrived → Delivering → Delivered · Cancel |
| **ร้านค้า** (`his_restaurant_status`) | Pending (รอรับ) → Accepted (รับออเดอร์) → Cooked (เตรียมอาหาร) → Waiting (รอจัดส่ง) → Delivering → Delivered · Cancel · Reject |
| **สถานะแอปคนขับ** (`driver_status`) | Available (เปิดรับงาน) · Delivery (กำลังรับงาน) · Offline (ปิด) · On Break / End Of Shift (ไม่ใช้) |
| **สถานะบัญชี** (`status`) | 0 = Inactive · 1 = Active · 2 = Block (มี `reason_block`) |
| **การจัดสรร** | `driver_assign_type` 0 = Auto, 1 = Manual · `driver_type` 0 = Rider Platform, 1 = Rider ร้าน, 2 = Other |

## Sitemap

- **เข้าสู่ระบบ:** เปลี่ยนภาษา (TH) · ลืมรหัสผ่าน · ลงทะเบียน · เงื่อนไขข้อตกลงและนโยบายความเป็นส่วนตัว
- **หน้าแรก**
  - เปิด/ปิดสถานะออนไลน์, current location, ยอดเครดิต, กระเป๋าเงินสด, สถานะการรับงานอัตโนมัติ
  - ข้อมูลสะสม: ระดับพาร์ทเนอร์, คะแนนคนขับ, อัตรารับงาน
  - ข้อมูลวันนี้: รายได้วันนี้, จำนวนงานเข้า, จำนวนงานที่รับ
  - การแจ้งเตือน
- **รับงาน:** ออเดอร์ (ไปยังร้านค้า) → ออเดอร์ (รับอาหาร) + รายละเอียดคำสั่งซื้อ → ออเดอร์ (ส่งอาหาร) + รายละเอียด + ลายเซ็นต์ → สรุปรายได้ · ยกเลิก
- **กระเป๋าเงิน**
  - ยอดเครดิต: ประวัติกระเป๋าเครดิต, ช่องทางการเติมเครดิต
  - กระเป๋าเงินสด: ประวัติกระเป๋าเงินสด, สรุปยอดรออนุมัติ
- **รายได้:** ประวัติรายได้รายวัน, รายเดือน
- **บัญชี:** ผู้ใช้งาน (ข้อมูลส่วนตัว, บัญชีธนาคาร, ข้อมูลยานพาหนะ), คะแนนคนขับ, การแจ้งเตือน, เปิด/ปิดรับงาน, เปิด/ปิดรับงานอัตโนมัติ, เปลี่ยนรหัสผ่าน, เปลี่ยนภาษา, คู่มือการใช้งาน, ติดต่อ Call Center, ออกจากระบบ
- **ติดต่อ:** Chat (ลูกค้า, ร้านค้า) · โทร (ลูกค้า, ร้านค้า, Call Center)

## ข้อมูลคนขับ (ตาราง `drivers`): ใช้ทำหน้า "รายชื่อไรเดอร์" ในหลังบ้าน

ฟิลด์หลัก: `driver_name`, `driver_img`, `phone_number`, `username`, `vechile_name` (ทะเบียนรถ), `payout` (perorder/distance), `payout_amount`, `device_name` (ANDROID/IOS), `is_logged`, `status` (Active/Inactive/Block), `driver_status` (Available/Delivery/Offline), `auto_accept`, `credit_wallet`, `cash_wallet`, `reason_block`, `partner_level`, ที่อยู่ปัจจุบัน/ตามบัตร, `driver_withdraw_round` (ครึ่งวัน/วัน/สัปดาห์/เดือน)

ตารางที่เกี่ยวข้อง: `partner_level` (ระดับพาร์ทเนอร์ เช่น โกลด์), `driver_color` (สีระดับตามจำนวน/อัตรารับงาน), `driver_bank`, `driver_document`, `driver_trackings` (พิกัด GPS), `driver_credit_wallet_histories`, `driver_income_wallet_histories`, `reviews` (`rating_driver`)

## การตั้งค่าระบบ

- `api_path.dart`: `endPoint`, `apiURL`, header `api_key` + `cctr_no`
- `settings_config`: URL เงื่อนไข/นโยบาย/FAQ/ลงทะเบียน ของร้าน คนขับ และลูกค้า · `store_near_km` (รัศมีค้นหาร้าน) · `user_review_endtime` · `rider_total_time` (เวลาจัดสรรคนขับสูงสุด) · เปิด/ปิดระบบเปลี่ยนภาษาแยกตามแอป
