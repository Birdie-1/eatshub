# 07c · BOH Module: Web Restaurant (Management for Store)

> สรุปจาก `07_FOC_BOHModule_WebRestaurant V1.0.pdf` (92 หน้า, v1.0)

## ภาพรวม

เว็บหลังบ้านสำหรับ **ร้านอาหาร** ใช้ดูแดชบอร์ดยอดขาย ตั้งค่าข้อมูลร้าน จัดการเมนู รับและอัปเดตออเดอร์เดลิเวอรี่ ดูรายงาน และสร้างข้อเสนอ/ส่วนลด ฟีเจอร์ชุดเดียวกับ [แอปร้านค้า](07a_BOH_Mobile_Restaurant.md) แต่เป็นเวอร์ชันเว็บ
- **Tech:** CakePHP + Bootstrap · MySQL `eatshub`
- **Layout:** เหมือน [Web Admin](07b_BOH_Web_Admin.md) (sidebar สีเทาเข้ม + "Restaurant Admin • Online", เนื้อหาเป็นการ์ดขาว, ปุ่มเหลือง/เขียว, ไอคอนสลับภาษาและออกจากระบบมุมขวาบน)
- **Sign In:** พื้นหลัง **สีเหลือง eatsHUB** ลายโลโก้ e + การ์ดขาว "กรุณาเข้าสู่ระบบ", Username/Password, ลืมรหัสผ่าน, ลงทะเบียน, Terms & Conditions / Privacy Policy

## Workflow

ใช้ workflow "การรับคำสั่งซื้อออเดอร์เดลิเวอรี่ออนไลน์ของร้านค้า" เดียวกับแอปร้านค้า: รอรับออเดอร์ → รับ/ปฏิเสธ (ระบุเหตุผล) → เตรียมอาหาร → รอจัดส่ง → (ไรเดอร์รับ) กำลังจัดส่ง → จัดส่งเรียบร้อย

## Sitemap

- **แดชบอร์ด:** ยอดขายทั้งหมด, ส่งแล้วทั้งหมด, คำสั่งซื้อทั้งหมด, ลูกค้าทั้งหมด, กราฟยอดขายรายเดือน, Top 10 อาหารขายดี, กราฟยอดขายรายวัน, ยอดขายตามประเภทเมนู, Top 10 ลูกค้ายอดสั่งซื้อสูงสุด
- เปลี่ยนรหัสผ่าน · **ตั้งค่า** · **จัดการเมนูอาหาร** · **ออเดอร์เดลิเวอรี่** · **รายงาน** · **ข้อเสนอ**
- Chat (ลูกค้า, คนขับ) · การแจ้งเตือน · ออกจากระบบ · ลืมรหัสผ่าน · ลงทะเบียน · เงื่อนไขและนโยบาย
