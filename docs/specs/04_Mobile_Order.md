## ภาพรวม

แอปมือถือของลูกค้า (iOS/Android, Flutter) ใช้ค้นหาร้านใกล้เคียง สั่งอาหาร ชำระเงิน ติดตามออเดอร์ และรีวิว ฟีเจอร์ชุดเดียวกับ [Order Web](03_Order_Web.md) และใช้ฐานข้อมูล MySQL `eatshub`

- **Bottom navigation 4 แท็บ:** ร้านอาหาร · ตะกร้า · ออเดอร์ · บัญชี (แท็บที่เลือกเป็นสีเหลือง)
- **สไตล์:** พื้นขาว การ์ดมุมโค้ง ปุ่มหลักสีเหลือง `#FCBB18` ตัวหนังสือเทาเข้ม ไอคอนหมวดอาหารแบบ flat สีสด

## Workflow: สั่งอาหารเดลิเวอรี่ (เหมือน Order Web)

ค้นหา location → ร้านที่เปิด → เลือกร้าน → เลือกเมนูลงตะกร้า → ชำระเงิน (ถ้ายังไม่เป็นสมาชิกให้ลงทะเบียนหรือเข้าสู่ระบบก่อน) → สรุปคำสั่งซื้อ + คูปอง + location + ค่าส่ง → หมายเหตุถึงร้าน/คนขับ → เลือกวิธีชำระ → ชำระสำเร็จ → ติดตามสถานะ → รีวิวร้านและคนขับ

**สถานะที่ลูกค้าเห็น:** 1. รอรับออเดอร์ → 2. ไปยังร้านค้า → 3. ถึงร้านค้า → 4. ส่งอาหาร → 5. จัดส่งเรียบร้อย · 6. ยกเลิก

## Sitemap

- **เข้าสู่ระบบ:** ลงทะเบียน · เปลี่ยนภาษา (TH) · ลืมรหัสผ่าน · เงื่อนไขข้อตกลงและนโยบายความเป็นส่วนตัว
- **ร้านอาหาร:** ค้นหาตำแหน่ง/เลือกที่อยู่, ค้นหาร้านอาหาร, Banner, ตัวกรองค้นหาประเภทร้าน, รายการร้านอาหารใกล้เคียง → **รายละเอียดร้าน** (แท็บ เมนู · ข้อมูล · ส่วนลด · คะแนน · รีวิว)
- **ตะกร้าสินค้า:** รายการสั่งซื้อ → คูปองส่วนลด → ชำระเงิน (เลือกที่อยู่จัดส่ง, การชำระเงิน)
- **ออเดอร์:** การสั่งซื้อของฉัน → รายละเอียดออเดอร์ (Chat, โทรหาร้านค้า/คนขับ/Call Center) → รีวิวร้านค้าและคนขับ
- **บัญชี:** ข้อมูลส่วนตัว, การแจ้งเตือน, บันทึกที่อยู่, ร้านค้าที่ถูกใจ, เปลี่ยนรหัสผ่าน, คะแนนสะสม, แนะนำเพื่อน, เงื่อนไขข้อตกลง, เกี่ยวกับเรา, FAQ, โทรหา Call Center, ออกจากระบบ
- **Chat:** ร้านค้า, คนขับ

## ลำดับหน้าจอ (รายละเอียดสำหรับ Mockup)

### 1. เข้าสู่ระบบ / ลงทะเบียน

### 3. ค้นหาร้าน
หน้าแรกแสดงร้านใกล้เคียงตาม location ล่าสุด → เปลี่ยน location (ช่องค้นหา + ที่อยู่ที่บันทึกไว้: บ้าน/ออฟฟิศ/ABPO) → พิมพ์ค้นหาหรือแตะหมวด → **ตัวกรอง** (รายการประเภทร้านแบบ radio + ปุ่ม "ค้นหา") → หน้าผลลัพธ์ (เช่น "อาหารไทย")
