# 07a · BOH Module: Mobile Restaurant (Mobile App for Store)

> สรุปจาก `07_FOC_BOHModule_MobileRestaurant V1.0.pdf` (91 หน้า, v1.0)

## ภาพรวม

แอปมือถือสำหรับ **ร้านอาหาร** ("eatsHUB ระบบการจัดการสำหรับร้านค้า") ใช้รับ/ปฏิเสธออเดอร์เดลิเวอรี่ อัปเดตสถานะ ดูประวัติและรายงาน เปิด/ปิดรับออเดอร์ และเปิด/ปิดเมนูที่ขาย
- **Tech:** Flutter · MySQL `eatshub`
- **Bottom nav 4 แท็บ:** ออเดอร์ · ประวัติ · รายงาน · บัญชี
- **Header:** ชื่อร้าน (เช่น "ราดหน้ายอดผัก (สาขาวัช…)") + กระดิ่งแจ้งเตือน (badge แดง) + ปุ่มรีเฟรช

## Workflow: รับคำสั่งซื้อเดลิเวอรี่ (Customer → Store → Rider)

1. ลูกค้าสั่งออเดอร์ → ร้านได้รับแจ้ง สถานะ **รอรับออเดอร์**
2. ร้านกด **ปฏิเสธ** (ยกเลิกพร้อมระบุเหตุผล → แจ้งลูกค้าและไรเดอร์) หรือ **รับออเดอร์** (สถานะ: รับออเดอร์)
3. **เตรียมอาหาร** → ทำเสร็จกด **รอจัดส่ง** → ไรเดอร์ได้รับแจ้งให้มารับอาหาร
4. ไรเดอร์รับอาหาร → **กำลังจัดส่ง** → ลูกค้าได้รับอาหาร → **จัดส่งเรียบร้อย (Delivered)** → ลูกค้ารีวิวร้านและคนขับ
5. ยกเลิกได้ระหว่าง "รับออเดอร์" ถึง "รอจัดส่ง"

**ลำดับ Action ของร้าน:** 1. รับออเดอร์ → 2. เตรียมอาหาร → 3. รอจัดส่ง → 4. กำลังจัดส่ง → 5. จัดส่งเรียบร้อย · 6. ยกเลิกออเดอร์

## Sitemap

- **เข้าสู่ระบบ:** เปลี่ยนภาษา (TH), ลืมรหัสผ่าน, ลงทะเบียน, เงื่อนไขข้อตกลงและนโยบายความเป็นส่วนตัว
- **ออเดอร์:** ออเดอร์ใหม่ · ออเดอร์ที่รับแล้ว · ออเดอร์ที่ส่งแล้ว · ออเดอร์ที่ยกเลิก → รายละเอียดคำสั่งซื้อ (Chat; โทรหาลูกค้า/คนขับ/Call Center) · แจ้งเตือน
- **ประวัติ:** ค้นหารายการประวัติ (เมื่อวานนี้, อาทิตย์นี้, เดือนนี้, สถานะ, วันที่)
- **รายงาน:** Top 10 อาหารขายดีที่สุด, กราฟยอดขายรายเดือน, กราฟยอดขายรายวัน, กราฟยอดขายตามประเภทเมนู, Top 10 ลูกค้ายอดสั่งซื้อสูงสุด
- **บัญชี:** เปิด/ปิดรับออเดอร์, จัดการเมนูอาหาร, แก้ไขโปรไฟล์, เปลี่ยนรหัสผ่าน, ออกจากระบบ
- **Chat:** คนขับ, ลูกค้า

## ลำดับหน้าจอ

| Flow | รายละเอียด |
|---|---|
| **Sign In** | โลโก้ "eatsHUB ระบบการจัดการสำหรับร้านค้า", Email/Password, ลืมรหัสผ่าน, ปุ่ม "ลงชื่อเข้าใช้งาน", ลงทะเบียน, Terms & Conditions / Privacy Policy |
| **ออเดอร์ใหม่** (หน้าเริ่มต้น) | แท็บ ออเดอร์ใหม่ / ที่รับแล้ว / ที่ส่งแล้ว / ที่ยกเลิก · การ์ด: ชื่อลูกค้า, เบอร์, เลขออเดอร์ `EH-BKK-210424-00012`, ยอด + วิธีชำระ (฿330 · เงินสด / ฿140 · บัตรเครดิต), Delivery, วันเวลา · ปุ่ม **ติดต่อ · รับออเดอร์ (เขียว) · ยกเลิกออเดอร์ (แดง)** |
| **รายละเอียดคำสั่งซื้อ** | คำสั่งซื้อ + ปุ่มโทร/แชท ลูกค้า, คนขับ, Call Center · สรุปรายการอาหาร (จำนวน/รายการ/ราคา: ต้มไทย 70, ต้มยำ 130, ต้มข่าวไก่ใส่เห็ด 70, ข้าวเหนียว ×6 60) · รวมค่าอาหาร ฿330, ส่วนลด −10, ค่าจัดส่ง 10, รวมคำสั่งซื้อ ฿330 · หมายเหตุถึงร้าน/คนขับ · ข้อมูลการชำระ (COD, ยังไม่ได้ชำระ) · ข้อมูลลูกค้า (ชื่อ, ที่อยู่, เบอร์, อีเมล) · ข้อมูลคำสั่งซื้อ (เลข, วันที่, เวลา) · ปุ่ม **ยกเลิกคำสั่งซื้อ / รับคำสั่งซื้อ** |
| **ที่รับแล้ว** | การ์ดมีสถานะ เช่น "กำลังค้นหาคนขับ" หรือ "ไรเดอร์: R00001" + dropdown Action สีเข้ม (เตรียมอาหาร / รอจัดส่ง / กำลังจัดส่ง) |
| **ที่ส่งแล้ว** | สรุปด้านบน "ออเดอร์ที่ส่งแล้ว 21 · รายได้ ฿5,751.25" + การ์ดพร้อมรหัสไรเดอร์ |
| **ที่ยกเลิก** | การ์ด + "ผู้ยกเลิก: ไรเดอร์-R00001 / ร้านค้า / ระบบ" + หมายเหตุสีแดง (เช่น "ไม่สะดวกรับงาน", "สินค้าหมด", "ร้านค้าปิดชั่วคราว") |
| **แจ้งเตือน** | แท็บ ทั้งหมด / รายการคำสั่งซื้อ / ข่าวสาร/โปรโมชั่น → แตะเพื่อเปิดออเดอร์ |
| **ประวัติ** | แท็บ เมื่อวานนี้ / อาทิตย์นี้ / เดือนนี้ + dropdown สถานะ · รายการ (เลขออเดอร์, ฿340, Delivery, ไรเดอร์ R00002, บัตรเครดิต, สถานะ จัดส่งเรียบร้อย/ยกเลิกออเดอร์) |
| **รายงาน** | dropdown เลือกรายงาน + KPI (ยอดขาย ฿12,500, จำนวนออเดอร์ 84) · Top 10 อาหารขายดี (กราฟแท่ง) · ยอดขายตามประเภทเมนู (pie: ต้ม 20%, ข้าว 30%, อื่นๆ 50%) · รายวัน (line) · รายเดือน (bar) · Top 10 ลูกค้า (ยอดสั่งซื้อและจำนวนออเดอร์) |
| **บัญชี** | โลโก้ร้าน + ชื่อ/เบอร์/อีเมล · toggle **เปิดรับออเดอร์** · จัดการเมนูอาหาร (ตาราง ลำดับ/ชื่อเมนู/หมวดหมู่/สถานะ toggle + ค้นหา/กรองหมวด) · แก้ไขโปรไฟล์ (ชื่อ, อีเมล, เบอร์) · เปลี่ยนรหัสผ่าน |
