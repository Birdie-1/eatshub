## ภาพรวม

เว็บหลังบ้านสำหรับ **Admin Platform** ใช้ดูแลทั้งแพลตฟอร์ม ได้แก่ แดชบอร์ด, ผู้ดูแลระบบย่อย, **ไรเดอร์**, ร้านอาหาร/เมนู/ข้อเสนอ, ออเดอร์, คูปอง, คะแนน, ลูกค้า, CMS, สถานที่ และรายงาน
- **Tech:** CakePHP + Bootstrap · MySQL `eatshub`
- **Layout:** โลโก้ eatsHUB บนแถบขาว + "ออกจากระบบ" มุมขวา · **sidebar สีเทาเข้ม (slate) ด้านซ้าย** มีโปรไฟล์ "Restaurant Admin • Online" ด้านบนและเมนูไอคอน (เมนูที่เลือกเป็นสีเหลือง) · พื้นที่เนื้อหาสีเทาอ่อน + การ์ดขาว · breadcrumb มุมขวาบน · **footer สีเหลือง** "Copyright © 2021 EatsHub. All rights reserved."
- **ตาราง:** แถบค้นหา + dropdown กรอง + ปุ่มเขียว "+ เพิ่มรายการ" · เรียงคอลัมน์ได้ · badge สถานะ · ปุ่ม ✏️ (เทาเข้ม) และ 🗑 (แดง) · pagination "แสดง 1 ถึง 10 จาก 17 รายการ"

## Workflow: ลงทะเบียนร้านค้าโดย Admin Platform (Admin → Store → POS)

1. ร้านค้าส่งข้อมูลการลงทะเบียน → Admin นำมากรอกลงทะเบียน: ข้อมูลติดต่อ → ข้อมูลร้านอาหาร → ข้อมูลการจัดส่ง → ข้อมูลคอมมิชชั่น → วิธีการชำระเงิน → โปรโมชั่นร้าน (ถ้ามี) → คะแนนสะสม → บันทึก → กำหนดวันเปิดร้านเบื้องต้น
2. ถ้าใช้ร้านค้าบน POS: ตรวจว่ามีบริษัทบน POS หรือยัง (ไม่มีให้สร้างบริษัทและกรอก Domain POS) → สร้างร้านบน POS และกรอกรหัสร้านค้า
3. ลงทะเบียนเรียบร้อย → ส่งรายละเอียดเข้าระบบให้ร้าน → ร้านเข้าระบบ กรอกข้อมูลร้าน สร้างเมนู → แจ้ง Admin รีวิวก่อนเปิดร้าน
4. Admin พิจารณาให้เปิดตามวันที่กำหนด (ถ้าไม่ผ่าน ร้านปรับปรุงข้อมูลแล้วส่งใหม่) → เปิดร้าน

### 2. ฟอร์มเพิ่ม / ข้อมูล Rider
แท็บ **ข้อมูล Rider** · **ข้อมูลสะสม**
- **ข้อมูลส่วนตัว:** รูปไรเดอร์ (อัพโหลด), รหัส Rider (EA0002 auto), เลขบัตรประชาชน, คำนำหน้า + ชื่อ, นามสกุล, เพศ, เบอร์โทร, วันเกิด, อายุ (คำนวณให้), รอบการเบิกรายได้ (รายวัน/รายเดือน…), ยอดเงินกระเป๋าเครดิตตั้งต้น
- **ข้อมูลความปลอดภัย:** Email, Password (Generate Password / Reset Password)
- **ที่อยู่ปัจจุบัน** และ **ที่อยู่ตามบัตรประชาชน:** บ้านเลขที่, ซอย/หมู่บ้าน, จังหวัด, เขต/อำเภอ, แขวง/ตำบล, รหัสไปรษณีย์
- **บัญชีธนาคาร:** ตาราง ธนาคาร/หมายเลขบัญชี/ชื่อบัญชี (+ เพิ่มธนาคาร)
- **ทะเบียนรถ:** ยี่ห้อ (Yamaha), รุ่น (Aerox), ทะเบียน (9กฉ2393), จังหวัด
- **เอกสาร:** สำเนาบัตรประชาชน, สำเนาทะเบียนรถ, เอกสารสัญญา, สำเนาทะเบียนบ้าน (ดู/แก้/ลบ)
- **ผู้ติดต่อกรณีฉุกเฉิน:** ชื่อ, นามสกุล, เบอร์โทร, ความสัมพันธ์

### 3. ข้อมูลสะสม (Rider Detail)
- **ข้อมูลสะสม:** วันเวลาลงทะเบียน, ระดับพาร์ทเนอร์ (โกล์ด ▾), คะแนนคนขับ ⭐ 4.00, อัตราการรับงานสะสม 98%, ข้อมูล ณ วันที่
- **ข้อมูลวันนี้** (ปุ่ม Refresh): เวลาที่ใช้ระบบล่าสุด, สถานะการรับงานอัตโนมัติ (เปิด), สถานะการรับงาน (Online), **สถานะ Rider / เหตุผล** (dropdown Active / Inactive / Block → ถ้าเลือก Block จะมี modal "Block Rider" ให้กรอกเหตุผลการ Block), Location GPS Active (lat,lng + ไอคอนแผนที่)
- **การ์ดยอด:** ยอดกระเป๋าเครดิต ฿820 · ยอดกระเป๋าเงินสด ฿1,230 · รายได้วันนี้ ฿2,820
- **ประวัติกระเป๋าเครดิต / เงินสด** (กรองเดือน/ปี)
- **รายการประวัติ Order การวิ่งงาน Rider** + "จำนวน รับงาน/งานเข้า 47 / 49": หมายเลขออเดอร์/วันที่, ร้านอาหาร, ยอดค่าอาหาร, รายได้ (60 ฿), สถานะรีวิว, คะแนนที่ได้รับ ⭐, สถานะงาน (จัดส่งเรียบร้อย / ยกเลิกออเดอร์ / ส่งอาหาร)

### 4. จัดการกระเป๋าเครดิต (การเติมเงินกระเป๋าเครดิต)
กรอง วันที่ Order + ช่วงวันที่ · คอลัมน์: ชื่อ-นามสกุล/รหัสไรเดอร์, ยอดเติม, ยอดก่อนเติม, ยอดหลังเติม, ช่องทางที่เติม/วันเวลาที่เติม (โอนผ่านธนาคาร), วันที่ได้รับข้อมูล, หมายเหตุ, ผู้แก้ไข

### 5. จัดการกระเป๋าเงินสด (การเบิกถอนเงินกระเป๋าเงินสด / รายได้ของ Rider)
